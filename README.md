# 项目历史问题 Skill

这是一项可独立使用的 Codex 技能，用于按项目维护 Markdown 问题记录。每个新对话默认关闭，明确开启后才会记录当前项目的问题。

## 项目结构

| 文件 | 用途 |
|---|---|
| [SKILL.md](SKILL.md) | 对话开关、记录检索、去重更新与验收规则 |
| [agents/openai.yaml](agents/openai.yaml) | 技能名称、调用提示和显式调用配置 |
| [references/issue-template.md](references/issue-template.md) | 新问题的五段式记录模板 |

## 使用方法

1. 将整个 `project-issue-history` 文件夹放入 Codex 的技能目录，或在对话中明确指定本项目的 `SKILL.md` 路径。
2. 在处理业务项目的对话里说「使用 `$project-issue-history`，开启本次对话的短链接项目历史问题记录」。通过文件路径使用时，用该路径指明技能。
3. 排查有进展时，技能会在业务项目中检索并更新对应条目。默认记录文件是业务项目根目录下的 `出现过的错误.md`，也可以指定现有记录文件。
4. 说「暂停记录」或「关闭记录」即可停止写入。切换业务项目或新开对话后，需要针对当前项目重新开启。

## 常用指令

| 指令 | 效果 |
|---|---|
| 开启历史问题记录 | 对当前对话和当前项目开启 |
| 开启，仅记录这条 | 记录当前问题后关闭 |
| 看看这个问题以前出现过没有 | 只读检索已有记录 |
| 这个问题解决了，更新一下 | 在记录开启时补充结果和验收证据 |

每条问题按问题表现、复现与现象、排查思路、解决经过、后续修复与验收记录。部分功能恢复时，已通过和待验证的场景分别写明。
